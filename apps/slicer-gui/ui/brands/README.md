# Printer brand marks

Single-path brand symbols drawn on the plate's front tab beside the
printer's manufacturer name (R120). They identify the printer the user has
chosen; they are not Sleptic's marks.

| File | Brand | Source |
|------|-------|--------|
| `anycubic.svg` | Anycubic | Simple Icons 13.21.0 (`icons/anycubic.svg`) |
| `elegoo.svg` | ELEGOO | Simple Icons 13.21.0 (`icons/elegoo.svg`) |

Simple Icons publishes its SVG data under CC0 1.0. The marks remain
trademarks of their owners and are subject to their brand guidelines.

A printer whose manufacturer has no file here shows its name alone; a
generic printer shows the Sleptic mark (`../../assets/images/sleptic.svg`).
To add a brand: a one-path, 24-unit SVG named after the manufacturer in
lower case, and an entry in `surface_text::brand_mark`.
