# Security

If you find a security problem in Sleptic Slicer (for example a crafted
model or project file that crashes the app, runs code or reads files it
should not), please report it privately rather than in a public issue: use
**Report a vulnerability** in this repository's **Security** tab. Say what
you found, how to reproduce it, and which version you used.

We will acknowledge the report, keep you informed while it is fixed, and
credit you when the fix is released unless you would rather not be named.
